# Data

- `raw/` contains the base host structures downloaded from the Materials Project, including `SiC_base.cif` and `GaN_base.cif`.
- `processed/` contains the generated doped CIF structures created from the raw hosts and transition-metal dopants.
- `graph_data/` contains the PyTorch Geometric graph dataset generated from the processed structures and their energy labels.
- `dopant_energies.csv` contains CHGNet energy values and the corresponding filenames used to build the graph dataset.

The `processed/` and `graph_data/` directories are gitignored and are regenerated by the pipeline.
